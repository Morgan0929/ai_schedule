# AI Schedule Agent — 移动端 (Flutter)

## 技术栈
- Flutter 3.x
- Dart 3.x
- HTTP 请求对接 Python 后端 API

## 启动
```bash
cd mobile
flutter pub get
flutter run
```

## 目录结构
```
mobile/
├── lib/           # Dart 源码
│   ├── main.dart
│   ├── screens/   # 页面
│   ├── services/  # API 调用
│   └── models/    # 数据模型
├── android/
├── ios/
└── pubspec.yaml
```
